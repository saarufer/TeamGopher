## 5. 审计风险和数据限制

- **历史净值登记误差**：日报逐行市值与报告总资产有时存在几美分至数美元差异；本数据集优先保留**当期报告的正式组合净值**，不偷偷修订。
- **行情真实性未独立核验**：原日报中的新闻与价格可能有供应商差异、未复核或错误。分析前请从独立行情源重取未复权收盘价，并将核验结果存入单独数据版本，不覆盖本档。
- **成交验证等级不同**：10月30日、11月2日的ETF买入系按事先限价规则及日内低价事后判定；日内最低价本身不证明订单生效后一定成交，必须标记为 *provisional_simulated_fill*。
- **账本现金舍入**：10月12日与10月19日的原登记现金流存在小额舍入差异，现金余额按当时冻结快照保留。
- **分红及公司行为**：尚未逐笔核对。价格收益与总收益不可混用。
- **原比赛终点**：一个月的挑战已结束，11月属于延长跟踪；没有可靠的官方最终结算日记录，不能用延长赛成绩替代原赛果。
- **数据间隔**：表中只包含有记录的日期，图表连线只为视觉连接，不意味着中间每日数据已知。

## 6. 本地模型/API分析建议

建议将 `Gopher_Daily_Performance.csv` 与 `Gopher_Trade_Ledger.csv` 一同送入本地分析程序，LLM只读取由Python计算的指标；所有事实需要附上 as_of、source、verification_status。

建议的分析任务：

- 计算组合与SPY的观察日收益差、滚动超额、最大回撤（明确非完整日频）、现金比例与超额的关系。
- 做反事实分析：保留原交易不变，另建“无10月19日减仓”“不做行业轮动”“恒定现金比例”等独立模拟分支。
- 对每个重大事件做 as-of 回放：只允许使用事件发生前已经发布的信息。
- 把组合回报拆分为市场Beta、行业暴露、个股特异性及现金拖累；无足够数据时只报告估计。
- 输出风险和审计告警，不得把预测当事实、把虚拟成交当真实成交。
